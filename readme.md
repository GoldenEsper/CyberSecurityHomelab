## About:
CompTIA Security+ certified Cybersecurity Practitioner with hands-on experience in cybersecurity lab environments, SIEM deployment and log analysis, threat simulation, and detection engineering.

This repository showcases practical cybersecurity projects and technical research focused on Security Operations Centre (SOC) workflows, security engineering, threat detection, and defensive security practices.

My work includes deploying a virtualised home lab using Proxmox VE, configuring network security and segmentation with OPNsense, centralising endpoint logs in Splunk, and simulating adversary techniques using Atomic Red Team to investigate events and develop detections mapped to the MITRE ATT&CK framework.

I use this repository to document technical implementations, investigation workflows, research, and lessons learned through hands-on experimentation.

I currently serve as an Electronics Technician in the Australian Defence Force, bringing a technical background and a disciplined approach to troubleshooting, systems, and continuous learning.
