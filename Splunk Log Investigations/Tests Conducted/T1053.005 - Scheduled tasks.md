## Alert Rule Created to detect attack

```
index="endpoint" EventID=4698
```

A simple detection rule was created for this alert as there are not many programs on the vulnerable system that requires filtering. In an more complex environent the following could be used.

```
index="endpoint" EventID=4698 NOT (TaskName IN ("*GoogleUpdate*", "*microsoftEdgeupdate*"))
```

Utilising the above command it is easy to update the alert with the required processes to ignore.

## Test 4
For the fourth test utilised the [[COM]] API to schedule the task. Specifically this code is utilising [[COM]] automation to open a "headless" (hidden) instance of word . It tells word create a doc and take text from a .txt file and inject it into the documents macro storage.

- Once finished it is saved as a .docm (word macro enabled document)
- Attack begins when human/script opens created word document and enables macros. Word executes code and the code calls windows API to schedule the desired task.

## Test 7
For this test the investigation was conducted without any prior knowledge of how the scheduled task operated. The following was found after filtering by EventID=1
![[Pasted image 20260922231019.png]]

The command line for this is as follows:
```
"powershell.exe" &amp; {$xml = [System.IO.File]::ReadAllText(\""C:\Users\VulnUser\Documents\AtomicRedteam\atomics\T1053.005\src\T1053_05_SCTASK_HIDDEN_ATTRIB.xml\"") Invoke-CimMethod -ClassName PS_ScheduledTask -NameSpace \""Root\Microsoft\Windows\TaskScheduler\"" -MethodName \""RegisterByXml\"" -Arguments @{ Force = $true; Xml =$xml; }}
```

This shows the operation of `Invoke-CimMethod` which indicates that WMI is utilised in the creation of the scheduled task. It is observed that the scheduled task is created at the folderpath of `"Root\Microsoft\Windows\TaskScheduler\"`. 

Upon filtering by time and `EventID=4698` the following is event is observed

The theory detailed above was mostly correct but neglected to mention that `$xml` was the variable used to store the xml data from the previously listed XML file. It also utilised RegisterByXML which takes a raw block of XML code and turns it into a running task.
