# Obfuscated PowerShell Detection (T1059.001) Summary
*Quick AI Summary*
Investigated and detected obfuscated PowerShell execution using Atomic Red Team test T1059.001. Validated Splunk Universal Forwarder XML field extraction, installed the Splunk Windows Add-On, and built alerts using `eval` and `rex` to parse Sysmon Event ID 1 logs for suspicious flags (`-enc`, `-w hidden`).

---

## Test Objective

- Observe logs for evidence of malicious use of powershell 
- Test system setup to confirm correct operation of test environment
## Initial Result

The first test was unsuccessful with the Splunk server not retrieving the correct fields from the XML. This made the investigation into the location of exact logs generated more difficult. In addition the Atomic-Invoker failed to run the Mimikatz script due to “Permissions denied”. 
## Troubleshooting test

Initially the splunk universal forwarder inputs.conf file was checked for correct configuration ensuring that the isXML = True line is included. Slight modifications to the order of the arguments were made within the file however the Splunk server was still not processing the XML data. Following this the splunk server was investigated and the Splunk Windows Add On which pulls the fields from the XML data was reinstalled. Upon server reboot after reinstalling the Splunk Windows Add On the Splunk server began extracting the fields from the XML data correctly.

Investigation into why the mimikatz script failed to run showed that RealTimeMonitoring was still operating even after being disabled in windows settings. The following powershell command was used to disable the RealTimeMonioring

```
Set-MpPreference -DisableRealTimeMonitoring $true
```

After this command was run Mimikatz was able to run after being called upon by Atomic-Invoker. The breakdown of this command is as follows:

- Set-MpPreference [CMDLET's](../../Studied%20Ideas%20and%20Concepts/2.%20Powershell%20Investigation/CMDLET's.md) to set configuration settings for windows defender
- DisableRealTimeMonitoring is a parameter
- $true is a boolean value passed to the parameter instructing defender to turn off real time monitoring

## Sysmon evidence

GST+8 3:19 10th of September 2026 test was conducted
![](../../Images/RegularImages/Pasted%20image%2020260926184948.png)

This log shows Powershell being used to run the malicious script Mimikatz.ps1 and it uses the parameter “-DumpCreds” which pulls credentials from LSASS (Local Security Authority Subsystem Service). LSASS runs in memory and enforces security policy, manages passwords, and generates access tokens. It generated a Sysmon EventID of 1 which indicates that a new process was created.  The command was no obfuscated by -encode which encodes the command in [Base64 Encoding](../../Studied%20Ideas%20and%20Concepts/2.%20Powershell%20Investigation/Base64%20Encoding.md)
