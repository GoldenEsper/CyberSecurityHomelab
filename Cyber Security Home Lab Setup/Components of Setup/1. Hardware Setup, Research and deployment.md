# Initial planning and research

For this project a HP EliteDesk 800 G3 is being used as it has room for future storage expansion and ease of repairability. 

  
Issues Identified

- The HP EliteDesk 800 G3 was fitted with 8Gb of DDR4 RAM, not enough to comfortably run ProxMox OS, Splunk Server, Vulnerable VM and Virtual Router. 
- Small amount of internal storage with single 500Gb disk for all server requirements
- Interaction from home PC to Virtual Machines to enable 
Issue mitigation

- Additional 8Gb of DDR4 RAM purchased and installed to increase total RAM to 16Gb of DDR4 RAM
- Small storage issue accepted however will likely cause future issues if old 500Gb dive ever requires replacement
# Implementation
- Objective: Install ProxMox onto server
- Steps taken:
 1. Create bootable drive with ProxMox installed
 2. Replace Windows on server with ProxMox OS
 3. Once setup interface with ProxMox via GUI on home PC
 4. Test installation correct by running a virtualised Ubuntu desktop
- Issues Identified: 
1. On initial boot the server required immediate restart as RAM configuration had changed since last boot. 
2. The server continued to boot Windows hard-drive even with the boot order correct. Incorrect .iso file was downloaded. The file used to build the bootable drive was for ARM processors. The correct .iso file download and creation of subsequent boot drive rectified issue.
3. During a test of ProxMox server virtualised Ubuntu Desktop failed to launch.. Error code pointed to virtualisation being disabled in BIOS settings. Once virtualisation turned on Virtual machine launched without issue
