Command Prompt is a command line interpreter that allows for file management, directory navigation and system configuration. The CMD line can perform basic tasks without the need for an advanced scripting language. It also provided direct access to operating system features and configurations.

Powershell is a command-line interface and scripting language. It was designed to automate administrative tasks, manage configs and provide control over the windows operating system. As powershell is object oriented it allows for actions to be performed on the properties of the objects retrieved. Powershell is integrated with the [[Framework .NET]] (.net framework) which allows it to leverage multiple libraries of classes, methods and properties. 

Overall CMD is often less favoured due to its simpler environment. However, CMD still provides simpler commands such as ping, tracert and IPconfig which can allow for faster feedback when troubleshooting.
