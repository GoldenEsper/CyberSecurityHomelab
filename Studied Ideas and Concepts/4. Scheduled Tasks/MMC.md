## What is it?
The Microsoft Management Console is used to create, save and open admin tools called consoles which manage hardware, software and network components of Windows Operating System.
## What are some examples?
- Computer management
- Active Directory
- Group policy management 
- Device manager
## What do MSC's have to do with it?

The management console can host [COM](COM.md) components called "snap-ins". A snap-in combined with MMC is called a "management saved console" with the file name `.msc` associated with it.
