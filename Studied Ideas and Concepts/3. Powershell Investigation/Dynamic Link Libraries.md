# What are Dynamic-libraries

Dynamic link libraries were created by microsoft that contains functions and data that can be used by multiple modules (application or DLL). DLL’s assist in reducing memory overhead when multiple applications by allowing common library code to be reused. Although DLL code can be shared, each process normally receives its own copy of the DLL’s data.
